## 2 · Оформлення за брендбуком 🟡

Брендбук KSE Business School від 29.10.2026. Повні токени й мапінг на MUI — на сторінці «Layout-референс».

- **Палітра:** `#004641` основний · `#2EC195` і `#60BE98` акценти · `#94D4C1` мʼята · `#EDEFEE` світле тло · `#111112` чорний · `#62005F` фіолетовий
- **Гарнітура:** Arial, без вебшрифтів
- **Радіуси 0.** `shape.borderRadius: 0` плюс оверрайди `MuiButton`, `MuiPaper`, `MuiTab`, `MuiChip`. Круглі лишаються статусні крапки й кільце вибору — це знаки, а не площини
- **Площини розділяються лінією в 1px**
- **Дві теми.** Світла: біла шапка, зелений логотип. Темна: `#111112`, логотип білий. `data-theme` на `<html>` плюс `ThemeProvider` із двома палітрами
- **Плашки** — базовий елемент: прямокутник із заливкою; дві впритул дають пару «підпис — значення»
- **Критичне** — фіолетовий `#62005F`, на темному `#D79BD4`. Один токен `--flag`

**+2 SP** до Етапу 5.

## 3 · Звʼязок курс × набір 🔴

Призначення курсу до набору — окремий запис із власним типом.

```
CourseOffering {
  courseId
  programCode        // MBA27 | MBA28 | …
  type               // core | elective
  lecturerId
  deadline
}
```

Один курс читається в кількох наборах і має в них власний тип. Risk Management — core у MBA27 і elective у MBA28.

Призначення робить менеджер або академічний директор. Поле `programCode` у `Syllabus` заповнюється з цього призначення.

**Силабус належить парі курс × набір.** Курс, що читається у двох наборах, має два силабуси, і матриця CLO → PLO в кожному рахується проти переліку ПРН свого набору.

**+2 SP** до Етапу 1. Робити разом із Етапом 1 — це фундамент для перевірок покриття.

## 4 · Кабінет 🔴

Один набір екранів на всі ролі. Роль дає права на ті самі екрани.

Академічний директор читає курси й пише силабуси, тому **My syllabi** в нього той самий екран, що й у викладача.

| Розділ | Instructor | Manager | Director |
|---|---|---|---|
| My syllabi | ✓ | ✓ | ✓ |
| Account settings | ✓ | ✓ | ✓ |
| All syllabi | | ✓ | ✓ |
| PLO coverage | | читання | ✓ |
| Courses & cohorts | | ✓ | ✓ |
| Course policies, Programme outcomes | читання | редагування | редагування |

**Вхід** — аватар у правому куті шапки відкриває меню: my syllabi, all syllabi, library, account settings, перемикач теми, вихід. Кабінет — окремий екран зі своєю лівою навігацією.

**Ліва навігація** згрупована за змістом: **My work** (my syllabi, account settings) · **Programme** (all syllabi, PLO coverage, courses & cohorts) · **Library** (course policies, programme outcomes, assessment components). Група `Programme` рендериться тим, хто має до неї права.

**Перемикач набору — один на застосунок, у контенті.** Зʼявляється на екранах, де набір має значення: All syllabi, PLO coverage, Programme outcomes.

## 6 · Розділ 2 силабуса — перенесення між силабусами 🟡

Викладач заповнює свої дані один раз, у першому силабусі. У кожному наступному силабусі того самого автора розділ 2 підставляється з попереднього, і викладач лише підтверджує або править.

Етап 6 виконується в цьому вигляді: **1 SP** замість трьох, зовнішніх джерел даних немає.

## 8 · PLO coverage 🔴

Матриця покриття на рівні програми — розділ кабінету.

Дані для неї збираються вже зараз: §7 ТЗ вимагає матрицю CLO → PLO всередині кожного силабуса. Матриця програми — та сама матриця, зібрана запитом по всіх силабусах набору.

Рядок — програмний результат набору. Стовпець — курс. Клітинка заповнюється з матриці силабуса.

| Стан | Значення | Вага |
|---|---|---|
| суцільна заливка | курс прямо формує результат | 1 |
| штрихування | торкається, не формує повністю | 0,5 |
| порожньо | курс цього результату не заявляє | 0 |

Колонка `Σ` — сумарне покриття кожного ПРН. Нуль означає, що програма обіцяє результат, якого не дає жоден курс набору. На даних MBA28 таких два: **ПРН7 — цифрові технології, дані та ШІ** і ПРН13 — організаційний дизайн.

Натискання клітинки відкриває праву панель: повний текст ПРН, результат курсу, який його закриває, і компонент оцінювання, яким це перевіряється.

**Вимога до збереження.** Матриця CLO → PLO зберігається рядками. Це вже є у вимозі «теми, кейси, рідінги й LO зберігаються як окремі записи» — звідси екран пишеться запитом.

**Офіційні формулювання ПРН лишаються українською**, як їх затверджено в освітній програмі. Англійською йдуть короткі мітки для матриці.

**+4 SP.** Новий Етап 13.
